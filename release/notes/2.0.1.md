MossStudio 2.0.1 带来两个新页面：「漫画」和重新设计的「训练」。导入模型改成拖进来就能用，ComfyUI、WebUI、Forge 里已有的模型也能直接用。生成失败时会说清楚原因并给出能用的办法，画板在卡片多的时候也更顺手。

## 漫画

- **新的「漫画」页**：写下一话的大纲，语言模型把它分成页和格，按格画图、配上对白气泡，最后导出成一页页漫画。需要先连接一个语言模型。
- **人物卡**：每个人物有外貌、性格、参考图、服装和 LoRA，让同一个人物在每一格里保持一致。
- **剧情记忆**：前几话发生的事会带进下一话的分镜。
- **分格**：分镜按页面的节奏选版式，对话、标准、动作、扉页各不相同，动作页可以有斜格和出血格。气泡可以直接在页面上拖动。
- 画图排着队进行，重启后接着画；每一格画好后等你点「通过」或写一句意见「重画」。

## 训练

- **围绕图片重新设计**：一个训练就是一组图片和它们的描述。训练过程中能看到每一步的样图，选出最满意的一步保存成 LoRA，再一键带到创作里试。
- 训练不再开单独的窗口，环境设置移到「设置 › 训练」。
- **GBC 打标**：用 KohakuGBC 给训练图片写描述，每一条都先给你看，接受了才写入。
- Windows 上的 NVIDIA 显卡现在会装上 CUDA 版的 PyTorch，以前装的是只能用处理器跑的版本。安装依赖时能看到每个包的下载进度。

## 导入模型

- **一个入口**：模型页右上角的「导入模型」可以选文件或文件夹，也可以直接把文件拖进窗口。
- **引擎先认一遍**：每个文件都会先问引擎它是什么、能不能用。认出是官方文件就直接用官方的名字；LoRA 和控制适配器会自动放进各自的列表。
- **自动拼成模型**：主模型、文本编码器和 VAE 一起导入时，会自动拼成一个能用的模型；缺哪一部分就只下载哪一部分。认不准怎么拼时，会打开「自己组合」并把认出来的文件预先填好。
- **用不了的文件说清原因**：比如「这是 FP16 版本，引擎读不了。换成 INT8 版本就能用。」，并附上能直接点的办法。
- **原地使用**：模型和 LoRA 都在原来的位置使用，不复制，不占额外空间。最后一步点「去创作」，导入的模型就已经选好了。
- **文件挪走了**：会显示「找不到文件」，可以「重新找到…」或「移除」，不会再让你重新下载。

## 用 ComfyUI、WebUI、Forge 里的模型

- 在模型页「添加来源」或「自动扫描」，就能接入 ComfyUI、Stable Diffusion WebUI、Forge 或自己的模型文件夹，同一种软件装了好几套也可以。
- 能用的模型和 LoRA 直接从原文件加载；用不了的收在一个默认折叠的清单里，并写明原因。
- 首次运行时可以选「使用已有模型」，只下载缺少的部分。
- 自动扫描只看常见的安装位置、已安装程序的列表和快捷方式，不读终端历史记录，也不读正在运行的程序。

## 创作

- **框选和小地图**：在空白处拖动可以框选多张卡片，一起移动、排整齐或删除。平移改为按住空格拖动、中键或右键拖动。卡片超出视野时右下角会出现小地图，按 F 显示全部。
- **更顺滑**：卡片多的时候拖动和平移不再卡顿。
- **解析**：顶部栏新增「解析」面板，读出一张图的提示词和区域框，可以复制提示词，或者直接「变成画面」。
- **生成失败说清楚**：显存不够时，卡片上写「显存不够这个尺寸」，并提供「改小一点再试」；引擎的原始信息在「查看详情」里。其他问题的修复按钮都会带你去真正能解决的地方。
- **起始图不再被裁成正方形**：还没生成过的画面会沿用第一张起始图的长宽比，已经画好的区域跟着一起缩放。
- **取消选图不留痕迹**：用配方选图时点了取消，画板保持原样。
- **开场更清爽**：这台电脑跑不了的配方不再显示。「底图」改名为「描图」，移到画面的 ⋯ 菜单里。

## 设置与安装

- **界面大小**：「设置 › 通用 › 界面大小」可以选「自动」，文字和按钮会随窗口一起放大；也可以固定为 100% 到 150%。
- **粘贴 SSH 登录命令**：添加远程主机时，把租用网站给的登录命令（如 `ssh -p 41234 root@…`）粘贴到「地址」，会自动填好地址、端口和用户名。
- **首次下载更可靠**：引擎或模型有一部分下载失败时，会单独显示原因和「重试」，其他部分照常下载；只有下载本身出错时才建议「换下载线路」。

## 修复

- Windows 上每日构建的安装包重新可以正常打包。
- 漫画页的数字输入框可以清空后重新输入，不会再把「2」变成「12」。

## 已知事项

- 首次加载 GGUF 格式的主模型时引擎要先转换一次，这段时间没有进度条。
- 安装包和程序尚未代码签名，第一次打开时系统可能提示来源未知。
