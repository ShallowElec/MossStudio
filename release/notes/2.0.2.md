MossStudio 2.0.2 让出图之后的事更顺手：画板可以撤销和重做，一个画面可以连着排好几张，图片能直接复制、另存和拖出去。语言模型统一在「设置 › 语言模型」里连接，密钥加密保存。

## 创作

- **撤销和重做**：画板上的改动都能撤销（Ctrl+Z，macOS 上是 ⌘Z）和重做（Ctrl+Shift+Z 或 Ctrl+Y），工具栏也有「撤销」「重做」。撤销后右下角会说撤销了什么，并能一键改回来。助手一轮里做的修改算一步，「撤销这一步」只撤销助手自己的改动。
- **删除卡片不再先问**：删掉的卡片可以在提示里「撤销」找回来，连同它的生成记录和连线。删除硬盘上的图片仍然会先确认。
- **再来一张**：画面正在生成时，可以接着点「再来一张」或按 Ctrl+Enter，新的一张会排在后面，最多排 8 张。⋯ 菜单里有「再来 4 张」和「取消排队的 N 张」。改了描述或设置后，可以「用新设置重画」当前这张。
- **LoRA 触发词**：选了 LoRA 后会读出它的触发词，点一下就写进描述，再点一下拿掉；也可以设置成自动加在描述前面或后面。来自风格的 LoRA 也一样。

## 图片

- 右键一张图片可以「复制图片」「另存为…」或「在文件夹中显示」，也可以直接把图片拖到别的程序或文件夹里。
- **作品页批量导出**：框选或多选几张图片后，「导出到文件夹…」一次导出，可以选只导出图片，或连同生成参数一起导出。多选后也能一起移到回收站。

## 语言模型

- **在设置里连接**：新的「设置 › 语言模型」列出所有连接，可以添加、编辑和移除，并分别选好谁给「助手和漫画」用、谁来「看图」。
- **用到的时候再连接**：生成分镜、写入剧情记忆、解析、拆成区域、打标和自动写描述在还没有语言模型时，会直接弹出连接窗口，连好后接着做刚才的事。
- **密钥加密保存**：语言模型的 API 密钥改为用系统的密钥环加密保存，和 GitHub、Hugging Face 的令牌一样。已保存的密钥会在启动时自动迁移。Linux 上用 Hyprland、Sway、i3 等桌面时，也会找到系统里的密钥环。

## 可选功能

「设置 › 功能」新增两个开关，默认关闭，关闭时相关按钮都不会出现：

- **外部 Agent**：让 Codex、Claude Code 等外部 Agent 通过 MCP 操作 MossStudio，并在助手旁边打开「协同」面板。外部 Agent 只能用你允许的工具、只能读作品和项目里的本地图片；删除、安装、训练等操作都要你确认。
- **Worker 远程主机**（实验性）：通过 SSH 连接运行 Worker 服务的远程主机，使用它自己的模型和 LoRA。

感谢 @BoltBlue121 贡献了外部 Agent、协同面板、LoRA 触发词和 Worker 远程主机的设计与实现。

## 修复

- 设置里点某个语言模型的「编辑」，打开的就是这个模型，不会再是上一个。
- 同一个画面连续很快地点生成时，排队数量不会再超过上限。

## 已知事项

- 首次加载 GGUF 格式的主模型时引擎要先转换一次，这段时间没有进度条。
- 安装包和程序尚未代码签名，第一次打开时系统可能提示来源未知。
